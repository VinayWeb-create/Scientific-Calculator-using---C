
# Scientific Calculator in C

This is a **Scientific Calculator** program built in C.  
It supports basic and advanced mathematical operations through a console interface.

---

## 🧾 Features

✔ Addition, Subtraction, Multiplication, Division  
✔ Modulus  
✔ Power  
✔ Square root  
✔ Trigonometric calculations (sin, cos, tan)  
✔ Factorial  
✔ More scientific operations
